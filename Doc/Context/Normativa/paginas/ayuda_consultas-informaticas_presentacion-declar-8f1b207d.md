 Incidencia Mensaje Opción no disponible al validar la declaración y generar el PDF para el modelo 303
Si se muestra el mensaje "Opción no disponible" al validar el modelo y generar el PDF, comprueba que no estés accediendo al modelo desde la opción "Favoritos" o "Marcadores" del navegador de internet.

Para solucionarlo, accede manualmente a los trámites del modelo 303 directamente desde la propia Sede.

Si persiste el problema, revisa los requisitos de acceso a la Sede.
